# 🏋️ Gamify Gym — Backend (Versão Antiga)

⚠️ **Atenção**  
Este repositório contém uma **versão antiga do backend** do projeto **Gamify Gym**, desenvolvida durante o período de **Trabalho de Conclusão de Curso (TCC)** na Etec Albert Einstein.  
O código está **arquivado**, servindo apenas como **registro histórico da evolução do projeto**.

---

## 📌 Sobre o Projeto

O **Gamify Gym** é um aplicativo voltado para **treino e dieta**, utilizando conceitos de **gamificação** para incentivar a constância e o engajamento dos usuários.

Este backend foi responsável por:
- Gerenciamento de usuários
- Cadastro de treinos e exercícios
- Controle básico de dados relacionados à dieta
- Comunicação com o frontend mobile da época

Atualmente, o projeto passou por **refatorações significativas**, com uma nova arquitetura e melhorias técnicas, cujo código **não é público**.
